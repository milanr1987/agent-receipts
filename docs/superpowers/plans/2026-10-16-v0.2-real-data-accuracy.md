# Agent Receipts 0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Agent Receipts give correct verdicts on real Claude Code 2.1.300 and Codex 0.125-0.162 sessions and ship it as a public, installable tool with English output and a BCS option.

**Architecture:** Keep the 0.1 layout (ingest adapters → normalized `Event` → claims → evidence → report). Add `messages.py` for all user-facing text, fix the two parsers against observed formats, make claim extraction markdown-aware, make test evidence runner-aware, add JSON output, a portable report location, packaging and POSIX launchers.

**Tech Stack:** Python 3.12+ standard library, `unittest`, setuptools (install time only), Windows cmd and POSIX sh launchers, Git CLI (read-only, `check-diff` only).

**Spec:** `docs/superpowers/specs/2026-10-16-v0.2-real-data-accuracy-design.md` (findings N1-N8 referenced below). Earlier design `docs/superpowers/specs/2026-10-15-portable-dual-agent-design.md` still governs runtime boundaries, privacy and hooks.

## Global Constraints

- Python `>=3.12`; runtime `dependencies = []`; no third-party imports in `src/`.
- No network, LLM or paid service at runtime. Never execute transcript content. Sessions and scanned projects are read-only.
- Default output language `en`; `--lang bs` or `RECEIPTS_LANG=bs` switches to BCS. Claim recognition stays EN+BCS regardless of output language.
- Report directory order: `--out DIR` → `RECEIPTS_HOME/reports` → `reports/` of a source checkout → `%LOCALAPPDATA%\agent-receipts\reports` (Windows) or `${XDG_STATE_HOME:-~/.local/state}/agent-receipts/reports`.
- Exit codes: 0 nothing flagged, 1 findings, 2 incomplete. Exit 2 only for: no sessions, explicitly given file that is unreadable/unknown, diagnostics `file_limit`, `line_limit`, `read_error`.
- Everything persisted or printed passes through `redact()`.
- macOS/Linux support is implemented, not verified; no CI (owner decision 2026-10-16).
- Hooks stay warning-only and fail-open; the tool never registers hooks.
- Work only on branch `v0.2-real-data-accuracy`. No `git push`, no merge into `main`, no PR without explicit owner confirmation.
- Financial rules in `AGENTS.md` apply (no paid services, credits or API keys).
- Owner session content never enters the repo or docs; docs get aggregate counts only.
- Test command (from checkout root, Git Bash): `PYTHONPATH=src python -m unittest discover -s tests -p "test_*.py" -v`. One module: replace the pattern, e.g. `-p "test_evidence.py"`. PowerShell: `$env:PYTHONPATH="$PWD\src"; python -m unittest discover -s tests -p "test_*.py" -v`.

## Review Focus

1. Claude `run_in_background` Bash results (`toolUseResult.backgroundTaskId`) mean the command has not finished; they must never count as a successful commit, push or test run. → Task 3, `test_background_bash_is_running_not_success`.
2. One summary-only or unknown-format `.jsonl` among hundreds found by discovery must not abort the whole audit with exit 2. → Task 4, `test_unknown_file_in_discovery_is_skipped`.
3. The most common Claude shape `cd "/dir" && python -m unittest` must stay a simple runner call (not "compound"), keeping CONFIRMED/CONTRADICTED. → Task 6, `test_setup_prefix_is_not_compound`.
4. A secret or quote characters inside a claim must leave `--format json` output valid JSON and redacted. → Task 7, `test_json_output_valid_and_redacted`.
5. `--lang` given after the subcommand (`receipts audit --lang bs`) and an invalid `RECEIPTS_LANG` (falls back to English). → Task 1, `test_cli_lang_after_subcommand` and `test_default_env_and_fallback`.

```python
TEXT_EXIT = re.compile(r'\A\s*Exit code:\s*(-?\d+)[ \t]*$', re.M)


def decode_output(raw):
    """Return (exit_code, output, status) for JSON or plain-text command output, or None."""
    if isinstance(raw, list):
        raw = text_content(raw)
    if not isinstance(raw, str):
        return None
    try:
        data = json.loads(raw)
    except ValueError:
        data = None
    if isinstance(data, dict):
        code = data.get('exit_code')
        code = code if type(code) is int else None
        return code, str(data.get('output', '')), 'completed' if code is not None else 'unknown'
    match = TEXT_EXIT.match(raw)
    if match:
        # Codex 0.125-0.159: "Exit code: N\nWall time: ...\n[Total output lines: N\n]Output:\n<text>"
        body = raw.split('\nOutput:\n', 1)
        return int(match[1]), body[1] if len(body) == 2 else raw[match.end():], 'completed'
    if raw.lstrip().startswith('execution error:'):
        # The sandbox refused to start the command: not a result in either direction.
        return None, raw, 'not_executed'
    return None
```

```python
import re
from .claims import runner, git_operation, command_segments
from .messages import t
from .models import Verdict

FAIL_RE = re.compile(r'(?im)\b[1-9]\d*\s+(?:failed|failures?|errors?)\b|FAILED\s*\([^)]*(?:failures|errors)=[1-9]|^FAIL\s*$|test result: FAILED')
PASS_RE = re.compile(r'(?im)^OK(?:\s|$)|\b\d+\s+passed\b|test result: ok')
# Jest "Tests: 1 failed, 94 passed, 95 total"; Vitest "Tests  95 passed (95)". Never "Test Files"/"Test Suites".
JS_TESTS_RE = re.compile(r'(?im)^\s*Tests:?\s+(?:\d+\s+\w+,\s*)*(\d+)\s+passed\b[^\n]*')
SUMMARY_RE = {
    'unittest': re.compile(r'Ran \d+ tests? in [\d.]+s\s+(?:OK|FAILED)[^\n]*'),
    'pytest': re.compile(r'(?m)^=+ [^\n]*\b(?:passed|failed|errors?)\b[^\n]*=+[ \t]*$'),
    'vitest': JS_TESTS_RE, 'jest': JS_TESTS_RE, 'npm': JS_TESTS_RE,
}
SETUP_SEGMENT = re.compile(r'(?i)^(?:(?:cd|pushd|set-location|export|set|source)\s|\.\s+\S*activate|\$env:\w+\s*=|\w+=\S*$)')


def _exit_failed(result):
    return bool(result.is_error) or (result.exit_code is not None and result.exit_code != 0)


def _failed(result):
    return _exit_failed(result) or bool(FAIL_RE.search(result.text))


def _successful(result, tests=False):
    if _failed(result) or result.status not in ('completed', 'success'):
        return False
    # The host success flag proves the shell exited 0, not that a runner reported a pass.
    if result.exit_code == 0 and not (tests and result.exit_source == 'host_success_flag'):
        return True
    if tests:
        return bool(PASS_RE.search(result.text))
    # Successful edit/write tool_result (not Bash) has a reliable tool success flag.
    return result.tool_name in ('Write', 'Edit', 'MultiEdit') and result.is_error is False


def _source(result):
    return f' [{result.exit_source}]' if result.exit_source else ''


def is_compound(command):
    """True when a runner shares the command with steps other than cd/env setup."""
    return any(not SETUP_SEGMENT.match(s) and not runner(s) for s in command_segments(command))


def runner_summary(name, text):
    pattern = SUMMARY_RE.get(name)
    matches = list(pattern.finditer(text)) if pattern else []
    return matches[-1].group(0) if matches else None


def test_count(name, text):
    if name == 'unittest':
        found = re.findall(r'\bRan\s+(\d+)\s+tests?\b', text)
    elif name in ('vitest', 'jest', 'npm'):
        found = JS_TESTS_RE.findall(text)
    elif name == 'pytest':
        found = re.findall(r'\b(\d+)\s+passed\b', text)
    else:
        found = []
    return int(found[-1]) if found else None


def _check_counts(claim, name, text):
    requested = re.search(r'(?i)\b(\d+)\s+(?:tests?|testova|testa|testovi)\b', claim.quote)
    actual = test_count(name, text)
    if requested and actual is not None and actual != int(requested[1]):
        return 'CONTRADICTED'
    skipped = re.search(r'(?i)skipped[=: ]+(\d+)', text)
    if skipped and int(skipped[1]) and re.search(r'(?i)without skips|no skips|bez preskakanja', claim.quote):
        return 'CONTRADICTED'
    return 'CONFIRMED'


def _test_verdict(claim, call, result):
    name = runner(call.text)
    proof = (t('proof_runner', call=call.line, runner=name, result=result.line,
               exit=result.exit_code, source=_source(result), status=result.status),)
    if is_compound(call.text):
        # Exit code and stray numbers belong to the other steps; judge the runner summary only.
        text = runner_summary(name, result.text)
        if text is None:
            return 'NO_EVIDENCE', (t('proof_compound', call=call.line),)
        if FAIL_RE.search(text):
            return 'CONTRADICTED', proof
        if not PASS_RE.search(text):
            return 'NO_EVIDENCE', proof
    else:
        text = result.text
        if _failed(result):
            return 'CONTRADICTED', proof
        if not _successful(result, tests=True):
            return 'NO_EVIDENCE', proof
    return _check_counts(claim, name, text), proof


def evaluate(session, claims):
    verdicts = []
    for claim in claims:
        preceding = [e for e in session.events if e.line < claim.event.line]
        # Events can share a JSONL line (Claude blocks). Earlier block order still matters.
        try:
            at = session.events.index(claim.event)
            preceding = list(session.events[:at])
        except ValueError:
            pass
        calls = {e.tool_id: e for e in preceding if e.kind == 'tool_call'}
        results = [e for e in preceding if e.kind == 'tool_result']
        status, proof = 'NO_EVIDENCE', (t('no_evidence'),)
        if claim.type == 'tests_pass':
            test_calls = [e for e in preceding if e.kind == 'tool_call' and e.turn == claim.event.turn and runner(e.text)]
            scopes = re.findall(r'(?i)\b(?:backend|frontend)\b', claim.quote)
            if scopes:
                test_calls = [e for e in test_calls if all(re.search(r'(?i)\b' + scope + r'\b', e.text) for scope in scopes)]
            if test_calls:
                call = test_calls[-1]
                result = next((e for e in reversed(results) if e.tool_id == call.tool_id and e.turn == claim.event.turn), None)
                if result:
                    status, proof = _test_verdict(claim, call, result)
        elif claim.type in ('committed', 'pushed'):
            operation = 'commit' if claim.type == 'committed' else 'push'
            for result in reversed(results):
                call = calls.get(result.tool_id)
                if not call or not git_operation(call.text, operation):
                    continue
                proof = (t('proof_git', call=call.line, op=operation, result=result.line,
                           exit=result.exit_code, source=_source(result)),)
                # Git output text (commit messages) is not a failure signal; only the exit is.
                if _exit_failed(result):
                    status = 'CONTRADICTED'
                elif result.exit_code == 0 and result.status == 'completed':
                    if operation == 'commit' and re.search(r'\[[^\]\n]+\s+[0-9a-f]{7,40}\]', result.text):
                        status = 'CONFIRMED'
                    elif operation == 'push' and re.search(r'(?im)\S+\s+->\s+\S+|Everything up-to-date', result.text):
                        status = 'CONFIRMED'
                break
        elif claim.type in ('files_changed', 'file_created'):
            successful = [e for e in results if _successful(e) or
                          (e.tool_name == 'file_change' and e.status == 'completed' and not e.is_error)]
            paths = set(p.replace('\\', '/') for e in successful for p in e.files)
            if claim.type == 'files_changed':
                if len(paths) >= int(claim.value or 0) and paths:
                    status = 'CONFIRMED'
                proof = (t('proof_files', n=len(paths)),)
            else:
                wanted = (claim.value or '').replace('\\', '/')
                for result in successful:
                    for path, action in result.file_actions:
                        path = path.replace('\\', '/')
                        if (path == wanted or path.endswith('/' + wanted)) and action == 'add':
                            status, proof = 'CONFIRMED', (t('proof_created', line=result.line),)
        verdicts.append(Verdict(claim, status, proof))
    return tuple(verdicts)
```

```python
REPORTS_DIR = None  # Explicit override (tests); see reports_dir().

def reports_dir(out=None, env=None):

    if out:
        return Path(out).expanduser()
    if REPORTS_DIR is not None:
        return REPORTS_DIR

def cell(value):
    return redact(str(value)).replace('&', '&amp;').replace('<', '&lt;').replace('>', '&gt;').replace('|', '\\|').replace('\n', ' ')


def render_report(results, skipped=0):
    lines = ['# Agent Receipts', '', t('report_note'), '']
    counts = Counter((session.source, verdict.status) for session, verdicts in results for verdict in verdicts)
    for source in ('codex', 'claude'):
        lines.append(f'- {source}: ' + ', '.join(f'{s}={counts[source, s]}' for s in STATUSES))
    if skipped:
        lines += ['', t('report_skipped', n=skipped)]
    if not results:
        lines += ['', t('report_empty')]
    lines += ['', t('report_header'), '|---|---:|---|---|---|']
    for session, verdicts in results:
        label = session.source + ' / ' + session.session_id + (t('subagent_label') if session.subagent else '')
        for verdict in verdicts:
            lines.append('| ' + ' | '.join(cell(x) for x in [label, verdict.claim.event.line, verdict.claim.quote,
                                                               verdict.status, '; '.join(verdict.evidence)]) + ' |')
        for diagnostic in session.diagnostics:
            lines.append('\n' + t('report_diagnostic', source=cell(session.source), line=diagnostic.line,
                                  code=cell(diagnostic.code), message=cell(diagnostic.message)))
        if not verdicts:
            lines.append('\n' + t('report_no_claims', source=cell(session.source), session=cell(session.session_id)))
    return redact('\n'.join(lines) + '\n')


def render_json(results, skipped=0):
    """Field-level redaction keeps the document valid JSON."""
    from . import __version__
    summary = {source: dict.fromkeys(STATUSES, 0) for source in ('codex', 'claude')}
    sessions = []
    for session, verdicts in results:
        for verdict in verdicts:
            summary[session.source][verdict.status] += 1
        sessions.append({
            'source': session.source, 'session_id': redact(session.session_id), 'subagent': session.subagent,
            'verdicts': [{'type': v.claim.type, 'status': v.status, 'line': v.claim.event.line,
                          'quote': redact(v.claim.quote), 'evidence': [redact(e) for e in v.evidence]} for v in verdicts],
            'diagnostics': [{'code': d.code, 'line': d.line, 'message': redact(d.message)} for d in session.diagnostics],
        })
    data = {'schema_version': 1, 'tool_version': __version__,
            'generated_at': datetime.now(timezone.utc).isoformat(timespec='seconds'),
            'summary': summary, 'skipped_files': skipped, 'sessions': sessions}
    return json.dumps(data, ensure_ascii=False, indent=2)


def save_report(text, name=None, out=None, already_redacted=False):
    directory = reports_dir(out)
    directory.mkdir(parents=True, exist_ok=True)
    path = directory / (name or (date.today().isoformat() + '.md'))
    path.write_text(text if already_redacted else redact(text), encoding='utf-8')
    return path
```

```python
"""Aggregate verdict counts over local sessions for one receipts source tree.

Usage: python tools/real_summary.py [--src DIR] [--since 30d] [--show STATUS]
Prints counts only. --show prints claim quotes of one status to this terminal;
never redirect that output into the repository.
"""
import argparse
from collections import Counter
import os
from pathlib import Path
import sys
import time

DEFAULT_SRC = Path(__file__).resolve().parents[1] / 'src'


def session_files(days):
    """Own file listing, so 0.1 and 0.2 are measured on exactly the same sessions."""
    home = Path.home()
    roots = [Path(os.environ.get('CODEX_HOME') or home / '.codex') / 'sessions']
    roots += [p / 'projects' for p in home.glob('.claude*') if p.is_dir()]
    if os.environ.get('CLAUDE_CONFIG_DIR'):
        roots.append(Path(os.environ['CLAUDE_CONFIG_DIR']) / 'projects')
    cutoff = time.time() - days * 86400
    found = set()
    for root in roots:
        if root.is_dir():
            found.update(p for p in root.rglob('*.jsonl') if 'subagents' not in p.relative_to(root).parts
                         and not p.is_symlink() and p.stat().st_mtime >= cutoff)
    return sorted(found, key=str)


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument('--src', type=Path, default=DEFAULT_SRC)
    parser.add_argument('--since', default='30d', help='Nd, days only')
    parser.add_argument('--show', choices=['CONFIRMED', 'NO_EVIDENCE', 'CONTRADICTED'])
    args = parser.parse_args(argv)
    sys.path.insert(0, str(args.src.resolve()))
    from receipts.ingest.detect import detect
    from receipts.ingest import claude, codex
    from receipts.claims import extract_claims
    from receipts.evidence import evaluate

    verdicts, diagnostics, sessions, skipped = Counter(), Counter(), Counter(), 0
    shown = []
    for path in session_files(int(args.since.rstrip('d'))):
        try:
            source = detect(path)
        except ValueError:
            skipped += 1
            continue
        session = (codex if source == 'codex' else claude).parse(path)
        sessions[source] += 1
        for code in {d.code for d in session.diagnostics}:
            diagnostics[source, code] += 1
        for v in evaluate(session, extract_claims(session.events)):
            verdicts[source, v.claim.type, v.status] += 1
            if v.status == args.show:
                shown.append(f'{source} {v.claim.type}: {v.claim.quote[:160]}')
    print('sessions', dict(sessions), 'skipped', skipped)
    for (source, typ, status), n in sorted(verdicts.items()):
        print(source, typ, status, n)
    for (source, code), n in sorted(diagnostics.items()):
        print('sessions_with_diagnostic', source, code, n)
    for line in shown:
        print('  -', line)
    return 0


if __name__ == '__main__':
    raise SystemExit(main())
```

````markdown
# Agent Receipts

Agent Receipts checks whether a coding agent's "done" messages are backed by evidence. It reads local Claude Code and Codex CLI session transcripts, finds claims such as "all tests pass", "committed" or "pushed", and looks for the earlier tool call and output that prove them. It can also flag weakened Python and JavaScript/TypeScript tests in a Git diff.

Everything runs offline with the Python standard library: no LLM, API key, account, server or network access.

> Experimental. A missing receipt is not proof that an agent lied, and test-weakening signals need human review.

## Usage

```sh
receipts audit --since 7d                      # all local Claude Code and Codex sessions from the last 7 days
receipts audit path/to/session.jsonl           # one transcript; the format is detected from content
receipts audit --source claude --profile .claude-work
receipts audit --project /path/to/project      # sessions whose working directory is this project
receipts audit --format json > receipts.json   # machine-readable output (schema_version 1)
receipts audit --include-subagents             # also audit subagent transcripts
receipts check-diff --project /path/to/project --base HEAD
receipts eval eval/labels.csv                  # precision/recall against your own labels
receipts audit --lang bs                       # Bosnian/Croatian/Serbian output (or RECEIPTS_LANG=bs)

Discovery reads `~/.codex/sessions` (or `CODEX_HOME`), every `~/.claude*/projects` profile directory and `CLAUDE_CONFIG_DIR`. Subagent transcripts are skipped unless `--include-subagents` is given; their final report already appears in the parent session. Files with an unknown format are skipped and counted in the report.

## Reading a report

| Status | Meaning |
|---|---|
| CONFIRMED | An earlier tool call and its output prove the claim. |
| NO_EVIDENCE | No usable proof was found. This is not proof the claim is false. |
| CONTRADICTED | An earlier result says the opposite, for example a failing run or a different test count. |

Illustrative row:

```text
| claude / 4f1c… | 812 | All 213 tests pass | CONTRADICTED | line 805: runner unittest; line 806: exit=0 [host_success_flag], status=completed |
```

Rules:

- Evidence must come before the claim. Test claims need a test runner in the same turn.
- `--help`, collect-only runs and dry-run pushes are not execution.
- When a runner shares a command with other steps (`pytest && build`), only the runner's own summary counts.
- Claude Code omits the exit code of successful commands; a result without the error flag counts as exit 0 (`host_success_flag`). Test claims still need recognizable runner output.
- A successful historical push does not verify the current remote. The tool never runs `fetch`, `ls-remote`, `push` or `commit`.

Exit codes: **0** nothing flagged, **1** claims to review, **2** incomplete (no sessions, an explicitly given file that is unreadable or unknown, or an oversized session).

Reports are written to `--out DIR`, else `$RECEIPTS_HOME/reports`, else `reports/` in a source checkout, else `%LOCALAPPDATA%\agent-receipts\reports` on Windows or `${XDG_STATE_HOME:-~/.local/state}/agent-receipts/reports`.
````
