# Agent Receipts 0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make daily use quiet and trustworthy: no false hook warnings, no exit 2 from one huge line, less claim noise, a report that shows what to review first, a hook under 1 s, plus the five 0.2 minors and an MIT license.

**Architecture:** Same pipeline (read_rows → detect → parse → claims → evidence → report). `read_rows` gains line skipping, a tail window and a row cap; detect and the parsers share one read. Claims gain exclusions; evidence gains `conversation_only`; the Markdown report is regrouped; the hook reads only the tail and checks only files the agent touched.

**Tech Stack:** Python 3.12+ standard library, `unittest`, Git CLI (read-only).

**Spec:** `docs/superpowers/specs/2026-10-16-v0.3-daily-use-design.md` (findings A-F, M1-M5, L).

## Global Constraints

- Runtime stays standard library only, offline, read-only; never execute transcript content; redact everything persisted.
- Hook stays warning-only, fail-open, exit 0.
- Output English by default, every new user-facing string added to both `en` and `bs` in `messages.py`.
- `FATAL_DIAGNOSTICS = {'file_limit', 'read_error'}` after Task 1.
- JSON `schema_version` stays 1; fields are only added.
- Work on branch `v0.3-daily-use`. No push, merge or PR without explicit owner confirmation.
- Tests (from checkout root, Git Bash): `PYTHONPATH=src python -m unittest discover -s tests -p "test_*.py"`; one module: `-p "test_x.py"`.
- Mind CRLF: `*.cmd` stays CRLF, `*.sh` LF. Write `\n` in test strings with the Edit/Write tools, not through heredoc-generated Python.

## Review Focus

1. A live transcript being appended while the hook reads it ends in half a JSON line; that must be a non-fatal `invalid_json`, never a crash or exit 2. → Task 1 `test_partial_last_line_is_not_fatal`.
2. Edit/Write paths on Windows arrive as `C:\Users\...\tests\Test_B.py` while Git reports `tests/test_b.py`; they must match. → Task 5 `test_hook_matches_windows_paths_case_insensitively`.
3. A hook or `check-diff` run whose cwd is a subdirectory of the repository must read the right files (Git paths are relative to the repository root). → Task 5 `test_changed_versions_from_subdirectory`.
4. A tail window that starts in the middle of a multi-byte UTF-8 character must not produce a diagnostic for the discarded fragment. → Task 1 `test_tail_window_drops_partial_first_line`.
5. A report with no sessions, or with only conversation mentions, must omit empty sections and exit 0. → Task 4 `test_conversation_only_report_exits_zero`.

```python
def read_rows(path, max_line=8 * 1024 * 1024, max_file=256 * 1024 * 1024, tail_bytes=None, max_rows=None):
    """Bounded JSONL reader. tail_bytes reads only the end of the file (rows numbered within the window)."""
    rows, diagnostics = [], []
    try:
        size = path.stat().st_size
        if tail_bytes is None and size > max_file:
            return [], [Diagnostic('file_limit', 0, t('diag_file_limit'))]
        with path.open('rb') as stream:
            if tail_bytes is not None and size > tail_bytes:
                stream.seek(size - tail_bytes)
                stream.readline()  # first line of the window is usually cut in half
            number = 0
            while max_rows is None or len(rows) < max_rows:
                raw = stream.readline(max_line + 1)
                if not raw:
                    break
                number += 1
                if len(raw) > max_line:
                    # Skip the rest of the oversized line without loading it; keep reading.
                    while raw and not raw.endswith(b'\n'):
                        raw = stream.readline(1024 * 1024)
                    diagnostics.append(Diagnostic('line_skipped', number, t('diag_line_skipped')))
                    continue
                if not raw.strip():
                    continue
                try:
                    row = json.loads(raw.decode('utf-8-sig'))
                    if not isinstance(row, dict):
                        raise ValueError()
                    rows.append((number, row))
                except (ValueError, UnicodeError):
                    diagnostics.append(Diagnostic('invalid_json', number, t('diag_invalid_json')))
    except OSError:
        diagnostics.append(Diagnostic('read_error', 0, t('diag_read_error')))
    return rows, diagnostics
```

```python
from .common import read_rows
from ..messages import t

FATAL_DIAGNOSTICS = {'file_limit', 'read_error'}


class UnreadableSession(ValueError):
    """A session that exists but could not be read; the audit must report itself incomplete."""


def detect(path, read=None):
    rows, diagnostics = read if read is not None else read_rows(path)
    fatal = [d for d in diagnostics if d.code in FATAL_DIAGNOSTICS]
    if fatal and not rows:
        raise UnreadableSession(fatal[0].message)
    for _, row in rows[:1000]:
        kind = row.get('type')
        if kind in ('session_meta', 'turn_context', 'response_item'):
            return 'codex'
        if kind == 'event_msg' and isinstance(row.get('payload'), dict):
            return 'codex'
        if kind in ('assistant', 'user') and isinstance(row.get('message'), dict):
            return 'claude'
    raise ValueError(t('unknown_format'))
```

```python
def session_label(session):
    when = (session.started_at or '')[:16].replace('T', ' ')
    parts = [p for p in (session.project, when) if p]
    tail = f'{session.source} {session.session_id[:8]}' + (t('subagent_label') if session.subagent else '')
    return ' · '.join(parts + [tail])


def render_report(results, skipped=0):
    lines = ['# Agent Receipts', '', t('report_note'), '']
    counts = Counter((session.source, verdict.status) for session, verdicts in results for verdict in verdicts)
    for source in ('codex', 'claude'):
        lines.append(f'- {source}: ' + ', '.join(f'{s}={counts[source, s]}' for s in STATUSES))
    empty = sum(1 for _, verdicts in results if not verdicts)
    lines += ['', t('report_counts', skipped=skipped, empty=empty)]
    if not results:
        lines += ['', t('report_empty')]
    order = {'CONTRADICTED': 0, 'NO_EVIDENCE': 1}
    review, conversation, confirmed = [], [], []
    for session, verdicts in results:
        flagged = sorted((v for v in verdicts if v.status != 'CONFIRMED' and not v.conversation_only),
```
