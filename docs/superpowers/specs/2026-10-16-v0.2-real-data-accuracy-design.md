# Agent Receipts 0.2: tačnost na stvarnim sesijama i javno izdanje

Datum: 2026-10-16. Status: spec odobren od vlasnika 2026-10-16 (bez CI-ja; macOS/Linux podrška bez provjere).
Odnos prema prethodnom dizajnu: `2026-10-15-portable-dual-agent-design.md` ostaje važeći za arhitekturu, granice runtimea, privatnost i hook pravila. Ovaj dokument ga dopunjuje i ima prednost tamo gdje se razlikuju.

## Namjera vlasnika

Alat postaje javni GitHub alat za druge korisnike Claude Codea i Codex CLI-ja, a vlasnik ga koristi i lično. "Perfektan" znači: tačne presude na stvarnim sesijama, instalacija na Windowsu, macOS-u i Linuxu, izlaz na engleskom uz BCS opciju.

Ograničenja ostaju: offline, bez LLM-a, samo standardna biblioteka u runtimeu, samo čitanje sesija i projekata, hook nikad ne blokira, finansijska pravila iz AGENTS.md.

## Obim 0.2

### 1. Claude parser (`ingest/claude.py`) — N1

- Rezultat Bash/PowerShell poziva bez eksplicitnog exit koda, sa `is_error` različitim od `true` i `toolUseResult.interrupted` različitim od `true`, dobija `exit_code = 0` i `exit_source = 'host_success_flag'`.
- `is_error: true` ostaje neuspjeh; exit kod iz teksta (`Exit code N`) ima prednost kad postoji.
- Novo polje `exit_source` u `Event` (`'explicit' | 'host_success_flag' | None`) ide u dokaz izvještaja, da korisnik vidi odakle je uspjeh izveden.
- Commit i dalje traži `[grana sha]` u izlazu, push `a -> b` ili `Everything up-to-date`. Uspješan exit bez tog izlaza ostaje NO_EVIDENCE.

### 2. Codex parser (`ingest/codex.py`) — N5

- `function_call_output` kao string: čitač teksta prepoznaje `Exit code: N` (obavezno), `Wall time:` i blok iza `Output:`. Bez `Exit code:` red ide u dijagnostiku kao do sada.
- `output` kao lista: tekst se sklapa preko `text_content`; exit kod samo ako je eksplicitan.
- Dijagnostika za pojedinačan nepodržan rezultat ne čini cijeli audit nepotpunim. Exit 2 ostaje za: nema sesija, nečitljiv fajl, `line_limit`/`file_limit`, nepoznat format sesije. Ostale dijagnostike se ispisuju, ali vode na exit 0/1.
- README navodi provjereni opseg Codex verzija (0.125 do 0.162) i Claude Code 2.1.300.

### 3. Izvlačenje tvrdnji (`claims.py`) — N2

Prije traženja obrazaca tekst prolazi kroz `strip_non_claims()`:
- uklanja blokove koda (```), inline kod, redove markdown tabela (počinju sa `|`), citate (`>`) i tekst pod navodnicima;
- zatim se dijeli na rečenice kao do sada.

`EXCLUDE` se proširuje: BCS budućnost i uslov (`ću`, `ćeš`, `će`, `ćemo`, `ćete`, `treba`, `trebalo`, `ako`, `kad`, `kada`, `cilj je`, `da bi`), EN `going to`, `once`, `until`, `goal`. BCS prezent namjere (`commitujem`, `pushujem`) se ne dodaje u obrasce, pa ne proizvodi tvrdnju.

Pravilo: proširenje mora zadržati sve postojeće testove pozitivnih tvrdnji ("commitovane su", "Svih 213 testova prolazi", "Testovi prolaze (56)").

### 4. Dokazi (`evidence.py`) — N3, N4, N8

- Broj testova po runneru, funkcija `test_count(runner, text)`:
  - unittest: `Ran N tests` minus `skipped=K` samo kad tvrdnja kaže "bez preskakanja"; inače se poredi `Ran N`;
  - pytest: `N passed` iz završnog sažetka;
  - vitest/jest: red koji počinje sa `Tests` (ne `Test Files`/`Test Suites`), `N passed`;
  - ostali: bez poređenja broja.
- Ispravka skip pravila: tvrdnja "213 testova prolazi" naspram "Ran 213 ... OK (skipped=2)" nije CONTRADICTED; jeste samo uz izričito "bez preskakanja".
- Složena komanda: kad poziv sadrži runner i još segmenata, `_failed` se primjenjuje samo na izlaz koji pripada runneru ako se može odvojiti (unittest/pytest/vitest/jest sažetak). Ako ne može, presuda je NO_EVIDENCE sa dokazom "složena komanda, izlaz runnera nije izdvojen", nikad CONTRADICTED na tuđem izlazu.
- N8 regresioni test: 213 naspram `Ran 212 ... OK` ostaje CONTRADICTED.

### 5. Discovery (`discovery.py`) — N6, N7

- `discover(home, ..., env=None)`: okruženje se prosljeđuje kao parametar (default `os.environ`); testovi prosljeđuju prazno okruženje.
- `--profile` prihvata bilo koji direktorij oblika `.claude*` u home-u; nepostojeći daje jasnu grešku.
- Fajlovi pod `subagents/` se preskaču po defaultu; `--include-subagents` ih uključuje i izvještaj ih označava kao `subagent`.

### 6. Jezik izlaza

- Novi modul `messages.py` sa rječnicima `en` i `bs`; sve poruke za korisnika (izvještaj, dokazi, dijagnostike, hook upozorenja, greške CLI-ja) idu preko `t(key, **args)`.
- Default `en`; `--lang bs` ili `RECEIPTS_LANG=bs`. Hook čita `RECEIPTS_LANG`.
- Prepoznavanje tvrdnji ostaje EN+BCS nezavisno od jezika izlaza.
- Test: svaki ključ postoji u oba rječnika.

### 7. JSON izlaz

- `audit --format md|json`, `check-diff` već piše JSON.
- Šema (`schema_version: 1`): `tool_version`, `generated_at`, `summary` (po izvoru: CONFIRMED/NO_EVIDENCE/CONTRADICTED), `sessions[]` sa `source`, `session_id`, `subagent`, `verdicts[]` (`type`, `status`, `line`, `quote`, `evidence[]`), `diagnostics[]` (`code`, `line`).
- Kodovi statusa i dijagnostika su stabilni engleski identifikatori; poruke slijede `--lang`.
- Sve prolazi kroz `redact()` prije ispisa. Exit kodovi isti kao za md.

### 8. Lokacija izvještaja i instalacija

- Redoslijed: `--out <dir>`, pa `RECEIPTS_HOME`, pa: ako postoji `reports/` pored izvornog `src/` (checkout) tamo; inače `%LOCALAPPDATA%\agent-receipts\reports` (Windows) ili `$XDG_STATE_HOME/agent-receipts/reports`, default `~/.local/state/agent-receipts/reports`.
- `pyproject.toml`: `[build-system]` sa setuptools, paket iz `src/`, `receipts = receipts.cli:main`. Runtime zavisnosti ostaju prazne.
- Podržano: `pipx install git+https://github.com/milanr1987/agent-receipts`, `uv tool install git+...`, Windows ZIP sa `setup.cmd`.
- macOS/Linux checkout bez pipx-a: `setup.sh` i `receipts.sh` kao ekvivalent `.cmd` skripti (venv bez pip-a, `PYTHONPATH=src`, `RECEIPTS_PYTHON`, isti exit kodovi) i `receipts-hook.sh` koji uvijek izlazi sa 0. Odluka vlasnika (2026-10-16): podrška se pravi, ali se na macOS/Linuxu ne provjerava; README to jasno kaže.
- `docs/hooks.md` dobija primjer hook komande za instaliranu `receipts` komandu (macOS/Linux) pored postojećeg `.cmd` primjera.

## Testiranje i validacija

- TDD: svaki nalaz N1 do N7 dobija test koji pada prije izmjene.
- Novi fixturei su ručno napisani po stvarnim formatima, bez sadržaja vlasnikovih sesija, i opisani u `tests/fixtures/PROVENANCE.md`:
  - `claude-2.1.300.jsonl`: uspješan Bash bez exit koda, neuspješan Bash, commit, push, tabela i inline kod koji nisu tvrdnje, BCS namjera;
  - `codex-text-output.jsonl`: `function_call` + tekstualni `function_call_output`;
  - stringovi vitest/jest izlaza i složene komande u unit testovima.
- Bez CI-ja (odluka vlasnika). Kod za putanje i okruženje koristi `pathlib`/`os` bez Windows pretpostavki; testovi koji zavise od Windowsa ostaju označeni `skipUnless`. Shell skripte se provjeravaju samo čitanjem i, ako je dostupan, Git Bashom na Windowsu.
- Privatni eval: `tools/real_sample.py` (u gitu) bira nasumični uzorak tvrdnji iz lokalnih sesija i piše `eval/labels.csv` (ignorisan) bez kolone `truth`; vlasnik je ručno popunjava; `receipts eval` računa TP/FP/FN.
- Isti uzorak se pušta na commit `1866c35` i na 0.2; u `docs/validation.md` idu samo agregati (broj tvrdnji, presude po tipu, lažne presude prije/poslije), bez citata.

## Kriteriji završetka

1. Svi testovi prolaze lokalno (Windows). macOS/Linux su podržani, ali neprovjereni, i README to navodi.
2. Na vlasnikovim sesijama: N1 commit/push tvrdnje sa stvarnim git dokazom su CONFIRMED; nema CONTRADICTED tipa N3/N4 u uzorku; N8 ostaje CONTRADICTED.
3. Broj Codex sesija koje izlaze sa 2 zbog `unsupported_result` je 0.
4. `pipx install` iz lokalnog checkouta daje radnu komandu `receipts --help` (provjereno na Windowsu).
5. Izlaz je na engleskom po defaultu; `--lang bs` daje BCS.
6. Ništa se ne pusha na GitHub i ne spaja u `main` bez izričite potvrde vlasnika.
